# My_lesson — веб-приложение для платформы онлайн-обучения

Курсовой проект по дисциплине «Разработка веб-приложений»

**Автор:** Пешкова У. И., группа 241-326  

## О проекте
Веб-приложение для организации смешанного и дистанционного обучения в школе. Позволяет преподавателям создавать курсы и уроки, загружать материалы, проводить тестирование, принимать работы учеников и отслеживать успеваемость. Ученики проходят обучение, выполняют задания и видят свой прогресс. Администратор управляет пользователями и контентом.

**Основные возможности:**
- Аутентификация и разделение ролей (ученик, учитель, администратор)
- CRUD-операции над курсами, уроками, тестами, вопросами
- Загрузка учебных материалов и сдача работ
- Автоматическая проверка тестов
- Статистика успеваемости с нормализацией баллов и расчётом прогресса

## Технологический стек
- **Backend:** Python, Flask, Flask-Login, Flask-SQLAlchemy, Flask-Migrate, WTForms
- **Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript
- **База данных:** SQLite (разработка) / PostgreSQL (production)
- **Развёртывание:** Облачная платформа Render
